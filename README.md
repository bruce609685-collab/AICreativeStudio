# AICreativeStudio · AI影音创造工坊

一个 AI 影音创作桌面工具：主程序本身**不调用任何模型**，生图、生视频、生语音的能力全部由 LLM自动生成的 Python 脚本提供。主程序只负责三件事——生成脚本、向脚本传递参数并执行、在界面中展示生成结果。

> ⚠️ **当前为 v0.5.1 版**：仍存在较多 BUG，界面也比较粗糙，欢迎提交 Issue 帮助改进！

## ✨ 功能一览

- **智能生成脚本**：首先在「智能导入」页面配置 LLM 模型，然后粘贴任意模型厂商的 API 接入文档，软件会调用 LLM 解析文档，自动生成符合软件使用要求的 Python 脚本
- **三类创作页签**：AI 生图片 / AI 生视频 / AI 生语音，包含输入参数和输出预览
- **历史记录**：使用 SQLite（轻量级数据库）存储，缩略图点击直接在预览宫格内回看，提示词回显
- **模型设置**：将你的 API KEY 写入脚本文件，代码可展开编辑
- **依赖自检**：依赖项一键下载并引导安装

## 📥 下载安装

从 [Releases](https://github.com/bruce609685-collab/AICreativeStudio/releases) 下载最新 zip 压缩包，**解压即用**（无需安装，支持 Windows 10 / 11）。

**首次使用**：

1. 打开「智能导入」页，配置你的 LLM 接口地址与密钥
2. 在「智能导入」页，粘贴模型API接口文档，生成脚本
3. 打开「模型设置」页，为你想用的脚本填入 API KEY
4. 打开生成页签，输入提示词、选择参数、点击生成

## 🚀 从源码运行

```bash
git clone https://github.com/bruce609685-collab/AICreativeStudio.git
cd AICreativeStudio
pip install -r requirements.txt
python main.py
```

## 📂 项目结构

```
AICreativeStudio/
├── main.py          # 唯一入口
├── about.py         # 程序身份信息（名称/版本/作者/发布页）
├── scripts/         # 制式脚本（图/视/音三目录，官方示例 7 个）
├── templates/       # 提示词模板（智能导入用）
├── ui/              # 界面层（6 页签 + 控件库）
├── core/            # 核心服务（脚本注册/执行/导入管线）
├── contract/        # 主程序与脚本之间的接口约定
├── infra/           # 基础设施（SQLite 历史库/网络/媒体）
├── domain/          # 领域模型
├── tests/           # 测试（pytest，88 用例）
├── docs/            # 界面截图（README 引用）
└── packaging/       # exe 版本资源生成 + 发布脚本
```

## 🛠 技术栈

| 层 | 选型 |
|---|---|
| 语言 | Python 3.12 |
| 界面 | PySide6（Qt） |
| 数据库 | SQLite |
| 打包 | PyInstaller（onedir，解压即用） |

架构上严格分层：`domain / contract / infra / core` 不依赖 GUI 框架，仅 `ui/` 引入 PySide6；脚本与主程序通过子进程 + JSON 协议通信，脚本崩溃不会影响主程序。
